# B&B Studio | Blush & Buzz

### Where Beauty Meets Influence

B&B Studio is a beauty-focused influencer discovery, campaign matching, and analytics platform built using Python, Flask, and modern frontend technologies.

The project combines curated fictional beauty creator profiles, rule-based campaign recommendations, historical influencer analytics, and a practical web scraping demonstration in a luxury editorial interface.

## Features

### Creator Discovery
Explore 10 fictional beauty creator profiles with searchable and filterable information, including follower counts, engagement rates, and content categories.

### Campaign Matchmaker
Enter campaign preferences and receive ranked creator recommendations using a transparent, rule-based matching algorithm.

### Analytics Studio
Explore influencer trends and engagement patterns using a historical Instagram influencer dataset with approximately 1,000 records.

### Data Atelier
Demonstrates web scraping, HTML parsing, data extraction, cleaning, and CSV export using Python.

### Creator Profiles
View individual creator information and explore potential campaign collaborations.

## How It Works

1. **Discover:** Explore curated beauty creator profiles.
2. **Match:** Enter campaign preferences and receive ranked recommendations.
3. **Analyze:** Explore influencer trends through interactive visualizations.
4. **Extract:** Demonstrate how public HTML data is collected, parsed, and structured.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Srishti140705/Blush-and-Buzz.git
cd Blush-and-Buzz
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python backend/main.py
```

Open `http://127.0.0.1:5000` in your browser.

## Dataset and Transparency

The analytics component uses a historical Instagram influencer dataset sourced from Kaggle.

The beauty creator personas, portraits, and associated demo statistics are fictional and are used for demonstration purposes.

Campaign matching is rule-based, not a trained AI recommendation model. Match results depend on the attributes available in the demo dataset.

The scraping demonstration uses publicly accessible practice content and is separate from the influencer analytics dataset.
